# 학생용 비행시간 계산기 개편안

작성일: 2026-10-08

이 문서는 논의를 위한 화면 구성 및 개발 순서 제안이다. 아래 버전 이름은 제안이며 현재 앱의 릴리스 버전을 뜻하지 않는다.

## 목표와 대상

고등학생이 기체와 배터리 조건을 바꿔 비행시간 변화를 이해하고, 자신의 입력이 어떤 결과를 만드는지 설명할 수 있는 계산기를 목표로 한다. 교사와 숙련 사용자는 같은 기체 설정에서 상세 입력, 계산 근거, 로그 검증으로 이어갈 수 있어야 한다.

첫 화면에서 다음 세 가지를 바로 파악하게 한다.

1. 지금 어떤 기체와 배터리로 계산하고 있는가?
2. 어떤 값을 바꾸면 되는가?
3. 예상 시간과 먼저 확인할 조건은 무엇인가?

## 현재 코드에서 확인한 문제 후보

현재 브라우저에 계산기 탭이 없어 실제 화면을 관찰한 결과가 아니라 JSX와 CSS에 기반한 진단이다. 학생의 실제 어려움은 개편 전후 사용 관찰로 확인한다.

- `src/components/ui.jsx`의 공통 입력 라벨은 12px, 입력값은 13px이며 결과 설명에는 10px 글씨가 있다. 작은 화면과 교실 환경에서 읽기 부담이 생길 수 있다.
- `src/App.jsx`와 고정익 입력 화면은 너비 280px 입력 영역을 사용한다. 이름, 입력값, 단위, 부가 설명이 좁은 영역에서 경쟁한다.
- 멀티콥터 결과 요약, 추력표 결과, 조합 판정에 시간과 전력 및 판정이 반복된다. 어떤 수치가 대표 결과인지 불분명해질 수 있다.
- 대표 시간은 선택한 추력표 또는 직접 입력 기준을 사용할 수 있지만 일부 요약 전력은 물리 모델 결과를 사용한다. 관련 지표가 같은 계산 기준을 사용하도록 점검해야 한다.
- 고정익은 기체 유형 선택 아래에 프리셋/사진 측정/커스텀 탭이 추가된다. 입력 자료를 고르는 행위가 다른 계산기처럼 보일 수 있다.
- ESC와 배터리 기본값, 효율 계수, 제조사 데이터, 실측 보정이 같은 작업 흐름에 섞여 있다. 초보자가 반드시 입력해야 하는 항목을 구별하기 어렵다.

## 권장 화면 구조

공통 골격은 모든 기체 유형에서 동일하게 유지한다.

```text
Sentiery 로고 / 비행시간 계산기                      저장 / 도움말
멀티콥터 | 고정익 | VTOL
계산 | 비교 | 비행 검증

입력 영역                              결과 영역
기체와 부품                            대표 예상 시간
배터리                                 전체 중량 / 소비전력
탑재물 또는 임무                        현재 조합에서 확인할 조건
상세 입력                              관련 그래프 1개
                                       계산 근거 펼치기
```

### 공통 탐색

- 기체 유형은 상단 탭으로 선택한다. 아이콘과 이름을 함께 표시한다.
- 작업 탭은 계산/비교/비행 검증으로 구분한다. 각 페이지에 선택 기체 요약이 보인다.
- 새로 고정익을 선택했을 때 기체 출처를 바꾸는 작업은 첫 입력 구역에서 한다. 추가 페이지 탭 대신 `기체 선택`, `사진으로 측정`, `직접 입력` 선택 컨트롤을 사용한다.
- 처음 열었을 때 사용 가능한 기체 프리셋과 기본 계산 결과가 보인다. 미입력 항목은 별도로 표시하며 데이터가 없다는 이유로 정상 판정을 만들지 않는다.
- 상세 입력 표시 여부를 바꿔도 입력값, 사진 측정 결과, 보정 설정은 보존한다.

### 계산 페이지

멀티콥터 기본 입력:

1. 기체 프리셋 또는 기체 구성
2. 모터-프로펠러 조합
3. 배터리
4. 추가 탑재물

고정익 기본 입력:

1. 기체 선택 또는 사진 측정
2. 전체 이륙중량
3. 모터-프로펠러 조합
4. 배터리

사진 측정은 기본 입력 영역의 작은 캔버스 대신 별도의 넓은 작업 화면으로 연다. 완료 시 측정 면적과 기체 설정으로 돌아온다. 휴대폰에서는 전체 화면, 데스크톱에서는 충분한 폭의 모달을 사용한다.

VTOL 기본 입력:

1. 기체와 전체 이륙중량
2. 수직비행 추진계
3. 순항 추진계와 주익 정보
4. 배터리와 임무 구간

상세 입력에는 ESC, 부품별 중량, 효율·공력 계수, 환경 조건을 배치한다. 태양광은 교육용 기본 제품 범위에서 제외한다. 상세 입력에 접혀 있는 설정 때문에 발생한 주요 불일치도 결과 요약에서 표시하고 해당 입력으로 이동할 수 있게 한다.

### 무게 입력 방식

`전체 무게 입력 | 부품별 합산`을 선택 컨트롤로 제공한다.

- 전체 무게 입력은 배터리와 탑재물을 포함한 실제 이륙중량이다.
- 부품별 합산은 기체, 모터, ESC, 배터리, 탑재물 등을 각각 입력한다.
- 입력 방식 변경 시 기존 값을 보존하고 현재 계산에 사용하는 방식이 표시된다.
- 두 방식의 중량을 함께 더하지 않는다.
- 기본 단위는 kg로 표시하고 소형 부품은 g 입력을 허용한다. 단위 변경 시 수치를 함께 변환한다.

### 대표 결과

대표 시간을 가장 크게 표시하고 나머지 지표는 한 줄의 요약으로 배치한다.

- 멀티콥터: 예상 호버링 시간, 이륙중량, 배터리 소비전력.
- 고정익: 예상 순항 체공시간, 적용 대기속도, 배터리 소비전력.
- VTOL: 예상 임무시간, 수직비행/순항 에너지 구성, 남겨둘 에너지.

남겨둘 배터리 잔량과 시간 계산 조건은 대표 결과 가까이에 표시한다. 여러 사용률별 시간을 기본 화면에 동시에 나열하지 않는다.

추력표, 사진 측정, 가정값, 로그 보정 같은 근거는 결과에 연결해 표시한다. 사진으로 면적을 구한 것과 공력이 실측 검증된 것은 구분한다.

가장 먼저 확인할 조건은 한 문장과 관련 수치로 표시한다. 전체 판정은 펼칠 수 있다. 추정 모델의 판정을 실제 비행 허가나 안전 보증으로 표현하지 않는다.

대표 시간·전력·전류·관련 부하 지표는 동일한 선택 모델을 사용한다. 물리 모델과 제조사 데이터 모델 비교는 계산 근거에서 별도로 제공한다.

## 컨트롤과 토글 배치

| 항목 | 컨트롤 | 위치와 동작 |
|---|---|---|
| 기체 유형 | 아이콘 + 이름 탭 | 상단, 모든 페이지에서 동일 |
| 계산/비교/검증 | 작업 탭 | 기체 유형 아래 |
| 기본/상세 입력 | 분할 선택 컨트롤 | 입력 영역 제목 옆, 상세값 보존 |
| 기체 정보 출처 | 선택 컨트롤 | 첫 입력 구역, 고정익의 세 번째 탭 줄을 대체 |
| 프리셋/부품 모델 | 드롭다운 | 해당 입력 구역 안 |
| 전체 무게/부품 합산 | 분할 선택 컨트롤 | 무게 구역 위, 현재 방식 명시 |
| 탑재장비 선택 | 체크박스 | 장비 목록의 각 행 |
| 비행 로그 보정 | 스위치 | 비행 검증 페이지의 보정 결과 옆 |
| 남겨둘 배터리 잔량 | 숫자 입력과 슬라이더 | 배터리 구역, 결과에도 현재값 표시 |
| 계산 근거/수식 | 펼치기 버튼 | 결과 아래 |
| 설정 저장/내보내기/초기화 | 아이콘 버튼 | 화면 공통 도구 영역, 툴팁과 접근성 이름 제공 |

토글은 켜기/끄기에만 사용한다. 기체 종류, 계산 방식, 여러 선택지에는 탭 또는 선택 컨트롤을 쓴다.

보정처럼 결과에 영향을 주는 옵션이 켜졌으면 결과 가까이에도 활성 상태가 표시된다. 보정 데이터가 없을 때 스위치를 활성화하지 않으며 검증 페이지에서 필요한 조건을 표시한다.

## 글씨와 시각 디자인

- Sentiery 로고와 기존 Lucide 아이콘을 활용한다.
- 흰색과 밝은 중립 배경, 짙은 회색 텍스트를 기본으로 한다. 브랜드 색은 선택 상태와 주요 작업에 사용한다.
- 초록/주황/빨강은 상태에 사용하며 아이콘과 상태 문구를 함께 표시한다.
- 본문과 입력값 16px, 라벨 14px, 부가 정보 13px를 시작점으로 검토한다. 작은 화면에서도 글씨를 더 작게 줄이지 않는다.
- 화면 제목 20-24px, 구역 제목 16-18px, 대표 시간 36-40px를 사용한다. 뷰포트 너비에 따라 글씨 크기를 연속적으로 바꾸지 않는다.
- 입력 및 주요 터치 컨트롤은 높이 44px를 제품 설계 목표로 한다. 이는 WCAG AA의 모든 항목에 적용되는 최소 높이라는 뜻은 아니다.
- 일반 텍스트의 대비는 최소 4.5:1을 확인한다.
- 데스크톱 입력 영역은 약 360-400px 폭을 시작점으로 한다. 입력 라벨과 숫자가 줄어들지 않게 한다.
- 페이지 구역은 여백과 구분선으로 나누고 반복 항목과 모달 등 필요한 곳에만 카드를 사용한다. 카드 안에 카드를 쌓지 않는다.
- 강조 효과와 반복되는 배지를 줄이고, 주요 결과에만 명확한 시각적 우선순위를 준다.
- 수식과 전문 용어는 계산 근거와 학습 설명에서 표시한다. 기본 라벨에는 한국어를 우선하고 필요한 기호와 단위만 붙인다.
- 수식의 단위와 의미를 설명하는 학습 내용은 제공하되 기능 소개나 사용법 문장으로 기본 계산 화면을 채우지 않는다.
- 입력이 비었을 때는 비어 있는 상태를 보존하고 해당 입력 가까이에 오류를 표시한다. 미완성 값을 0으로 바꾸어 결과를 정상처럼 표시하지 않는다.

모바일에서는 입력과 결과를 한 열로 배치한다. 화면 하단 요약에는 대표 시간과 결과 이동 버튼 정도만 표시한다. 키보드와 함께 열렸을 때 입력칸을 가리지 않도록 접고, 고정 영역만큼 페이지 하단 여백을 확보한다.

## 비교 페이지

현재 기체 설정을 기준안으로 저장하고 한 항목만 바꾼 변경안과 비교한다.

- 대표 차이: 시간, 전체 무게, 소비전력.
- 배터리 또는 탑재물 변경 시 무엇이 바뀌었는지 표시한다.
- 배터리 용량 증가에 따른 무게 변화를 함께 반영한다. 새 배터리 무게가 불명확하면 입력이 필요하다는 상태를 표시한다.
- 로그 보정은 적용 가능한 조합에서만 유지하고 다른 조합에 대한 외삽은 표시한다.
- 그래프는 한 번에 한 가지 질문을 보여준다. 예: 탑재물 무게에 따른 시간, 대기속도에 따른 전력.

## 비행 검증 페이지

앞서 논의한 시험 계획, 로그 분석, 보정 결과, 별도 비행 검증을 한 흐름으로 구성한다.

- 시험 조건에는 기체 구성, 전체 중량, 배터리, 시험 속도 범위, 임무 구간이 포함된다.
- 시험 로이터 반경과 귀환 에너지 기준 운용거리는 다른 항목으로 표시한다.
- 시험 종료는 고정 잔량 15%가 아니라 귀환·접근·착륙·예비 에너지와 기체 운용 한계를 반영한다.
- 로그에서 직선 수평비행, 선회, 상승, 하강과 착륙을 구분한다.
- 대기속도와 지상속도의 출처를 구분한다. 대기속도 자료가 없으면 보정의 제약을 표시한다.
- 보정용 로그와 검증용 로그를 구분해 같은 로그로만 정확도를 평가하지 않는다.
- 전체 비행시간뿐 아니라 동일한 구간의 예측/실측 소비 Wh를 비교한다.
- 검증 이력에는 보정 버전, 당시 설정, 적용 범위, 예측 오차를 저장한다.
- 로그 원본이나 위치를 외부로 공유하는 작업은 별도의 명시적인 동의 흐름을 유지한다.

| v0.4 | 고정익 사진과 추진계 | 넓은 사진 측정 화면, 윤곽 수정, 촬영 보정 지원, 측정 출처 표시, 모터-프로펠러 성능 연결 | 공개 치수와 사진 측정 결과를 비교, 입력 자료 적용 범위 확인 |

사진 윤곽 자동 인식은 v0.4 이후 실제 측정 실패 사례를 바탕으로 우선순위를 정한다. 원근 보정과 사용자 수정이 가능한 측정 흐름을 먼저 확보한다.

## 학생 사용성 확인

처음 사용하는 학생 3-5명을 대상으로 개편 전후에 같은 과제를 수행하게 한다. 소규모 관찰은 문제를 찾기 위한 것으로 통계적인 효과를 입증하는 시험은 아니다.

| 과제 | 관찰할 것 |
|---|---|
| 처음 화면에서 예상 시간과 선택 기체 찾기 | 첫 시선과 소요 시간, 잘못 읽은 숫자 |
| 배터리 용량과 무게를 바꾸기 | 입력 위치를 찾는지, 단위를 이해하는지 |
| 탑재물 추가 후 변화 설명하기 | 시간과 전체 중량의 관계를 이해하는지 |
| 조합 확인 항목 하나 해결하기 | 해당 입력으로 이동하고 필요한 값을 찾는지 |
| 고정익의 기체 선택과 사진 측정 구분하기 | 정보 출처와 계산 결과를 혼동하는지 |

초기 목표는 대표 결과를 약 10초 안에 찾고, 교사의 조작 설명 없이 첫 조건 변경을 약 2분 안에 수행하는 것으로 설정한다. 이는 제품 목표이며 관찰 결과에 따라 조정한다.

가독성은 교실 노트북, 학생 휴대폰, 확대 화면에서도 확인한다. 실제 수업에서 사용하는 기기를 기준으로 입력과 결과 이동, 키보드 표시, 글씨 줄바꿈을 점검한다.

## 먼저 진행할 작업 묶음

1. 대표 결과와 계산 기준을 정리하고 중복 지표를 계산 근거로 이동한다.
2. 공통 입력 컴포넌트의 라벨, 글씨, 폭, 단위, 빈 값, 키보드 포커스를 개선한다.
3. 기본/상세 입력과 기체별 공통 탐색 구조를 적용한다.
4. 옵션과 보정 활성 상태를 결과에 연결한다.
5. 데스크톱과 모바일에서 학생 과제를 확인하고 v0.3 비교 기능으로 이어간다.
