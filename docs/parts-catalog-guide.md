# 제조사별 부품 데이터 관리

학생용 계산기(`index.html`)의 부품 선택 데이터다. eCalc의 데이터나 코드를 복제하지 않는다. 기존 상세 계산기(`advanced.html`)는 별도 계산 흐름을 유지한다.

## 모터와 추력표

`src/student/parts-catalog.json`의 `motorFiles`에 기록된 CSV를 `public/data/`에서 읽는다. 현재 `motor-presets.csv`, `sunnysky-motors.csv` 두 파일을 포함한다. 제조사/모델/KV로 모델을 묶고, 프로펠러와 시험 셀·전압으로 시험 조합을 구별한다.

기존 CSV에 조합을 추가하면 자동으로 선택 목록에 나타난다. 파일을 따로 추가할 때는 다음 순서로 작업한다.

1. 동일한 열 형식으로 `public/data/새파일.csv`를 만든다.
2. `src/student/parts-catalog.json`의 `motorFiles`에 `새파일.csv`를 추가한다.
3. 같은 JSON의 `comboMetadata`에 조합 `id`별 프로펠러 제조사, 스로틀 자료 제공 여부, 제한 전류의 지속시간을 기록한다.
4. `npm test`, `npm run build` 후 부품 선택과 시험 조건을 확인한다.

등록 파일 중 하나를 읽지 못하면 목록 전체 대신 자료 로드 오류를 표시한다. 누락된 시험표를 물리 모델로 조용히 대체하지 않는다.

기존 CSV 형식은 `docs/motor-csv-guide.md`를 참고한다. 모델 이름이 같아도 KV가 다르면 별도 모델로 취급한다. 서로 다른 시험 전압·프로펠러는 고유한 `id`가 필요하다.

### SunnySky 추가 목록

| V2806 400 KV | 6S / 22.2 V | 47 g | EOLO CN11x4.5, CN12x5 | 10 A / 180초 |
| V2806 650 KV | 4S / 14.8 V | 47 g | EOLO CN11x4.5, CN12x5 | 16 A / 180초 |

공식 표의 정지 추력·전력·전류·RPM 측정점을 옮겼다. 추력 gf는 기존 CSV의 `thrust_g` 열에 기록하며 화면에서는 N으로 환산한다. 전력은 제조사 표의 반올림된 W 값을 유지하며 전압×전류로 덮어쓰지 않는다.

SunnySky 표에는 측정점별 스로틀 %가 없다. `throttle` 열을 비워 두고 `src/student/parts-catalog.json`의 해당 조합에 `throttleAvailable: false`를 반드시 기록한다. 학생용 계산기의 변환 계층에서 이를 `null`로 처리한다. 호버 전력·전류는 필요 추력에 맞춰 보간하지만 50% 성능, 호버 스로틀 %와 스로틀 여유는 생성하지 않는다. 상세 계산기의 기존 CSV 로더에는 빈 숫자 열을 0으로 읽는 동작이 있으므로 SunnySky 파일의 행을 `motor-presets.csv`에 그대로 합치면 안 된다.

최대 전류 표기에 지속시간이 있으므로 무제한 연속 운용 정격으로 취급하지 않는다. 시험 최대 추력 역시 연속 비행 가능한 추력을 보증하지 않는다. 프로펠러 개당 무게는 미확인으로 실측 입력이 필요하다. 프로펠러 장착·직경 간섭 및 ESC 선정은 실제 기체에서 별도로 확인한다.

출처:

- [SunnySky V2806 공식 자료](https://sunnyskyusa.com/products/sunnysky-v2806-motor)
- [SunnySky V3508 공식 자료](https://sunnyskyusa.com/products/sunnysky-v3508-motor)

V3508의 낮은 KV 옵션은 공식 페이지 탭의 380 KV와 스펙 표의 350 KV 표기가 달라 이번 목록에서 제외했다. 실제 모터 버전이 확인되면 별도 조합으로 추가한다. 이번 목록은 사이트 전체 모델 목록이 아니며 시험이 확인된 8개 조합만 포함한다.

## 프로펠러 제조사

모터 제조사와 프로펠러 제조사가 같다고 자동으로 가정하지 않는다. `src/student/parts-catalog.json`의 `comboMetadata`에 추력표 `id`별 `propMaker`를 기록한다. 미등록 제조사는 `제조사 미확인`으로 표시한다. Holybro는 키트의 등록 출처로 표시한다.

등록 추력표가 있는 프로펠러 조합만 모델 선택에 표시한다. 다른 프로펠러는 동일한 인치라도 기존 추력표를 재사용하지 않는다. 별도 추력표를 추가하거나 50% 스펙을 직접 입력한다.

CSV의 프로펠러 무게 0은 기존 자료에서 미등록값이므로 학생용 계산기에서는 누락으로 해석한다. 부품 합산에서는 실측값을 입력해야 결과를 표시한다. 전체 이륙중량을 직접 입력하는 경우에는 부품 무게를 또 더하지 않는다.

## ESC

`src/student/parts-catalog.json`의 `escs`에 항목을 추가한다. 단위는 `weightG`는 g, `continuousA`·`peakA`는 A, `cellMin`·`cellMax`는 셀 수다. 모르는 무게·순간 전류는 `null`로 둔다. 자료 출처 `sourceUrl`과 배선 포함 여부/순간 전류 지속시간 등 `note`를 기록한다.

학생용 계산기는 개별 ESC를 로터 수만큼 합산한다. 4-in-1/AIO는 아직 지원하지 않으므로 4배 합산하는 모델에 그대로 등록하지 않는다.

출처:

- Holybro X500 V2 BLHeli S 20A: https://docs.holybro.com/drone-development-kit/px4-development-kit-x500v2
- T-MOTOR AIR 20A 3–4S: https://store.tmotor.com/product/air-gear-450II-combo-set.html
- T-MOTOR AIR 40A 2–6S 정격과 지원 셀: https://uav-en.tmotor.com/Multirotor/ESC/air/

등록되지 않은 ESC는 직접 입력 가능하다. 순간 정격으로 연속 운용 가능 판정을 만들지 않는다. 제조사 허용 셀 범위와 전류는 스펙 판정 자료이며 펌웨어·프로토콜·장착 호환성을 보증하지 않는다.

## 계산 범위

멀티콥터는 선택한 모터·프로펠러·전압의 정지 추력표로 호버 전력을 계산한다. 배터리 셀 수가 시험 셀 수와 다르면 시간 대신 불일치를 표시한다. 50% 한 점 직접 입력은 기존 앱과 같은 추력비 기반 근사 모델이며 전체 추력 곡선을 대신하지 않는다.

고정익 순항 시간은 여전히 기존 공력 모델과 추진 효율 가정값 기준이다. 정지 추력표 선택만으로 순항 추진계 성능을 모델링했다고 보지 않는다. 학생용 VTOL은 베타 추정 화면이며 수직/순항 추진계 분리는 후속 작업이다. 기존 상세 계산기의 임무 설계·로그 보정 기능은 `advanced.html`에서 계속 제공한다.

## 비교 기준 저장

현재 계산 결과의 시간·전체 무게·전력 등을 기준안 하나로 저장한다. 입력 변경은 기준안 결과를 바꾸지 않으며, 조건 비교 탭에서 현재 구성과 차이를 표시한다. 다시 저장하면 기준안을 덮어쓴다.

기준안은 React 메모리에만 보관하고 새로고침·페이지 이동·탭 종료 시 사라진다. 서버 업로드나 계정 저장을 수행하지 않는다. 설정 내보내기는 별도의 JSON 파일 다운로드이며, 기준안 저장과 다르다. 설정 다시 불러오기와 비교안 영구 보관은 아직 구현하지 않았다.
